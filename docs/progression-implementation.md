# 成长准备：版本依据与不变量

玩家操作见 [成长准备](progression.md)。以下依据只对应 `schemas/thepiper-2026-09-25/` 记录的两个游戏文件 SHA-256。

## 工坊升级

| RVA | 已确认行为 |
| --- | --- |
| `0x620190` | 返回工坊 CurrentRank |
| `0x622EC0` | 先确认下一等级配置存在，再按当前等级 ShopRankConfig 行检查四项门槛 |
| `0x6205E0` | 通过检查后提升一级，执行解锁流程，按新等级 boaq 授予炼金点数 |
| `0x622AE0` | 发放该等级建筑、配方，刷新相关系统并发送事件 |
| `0x623120` | 按实际建筑与地图升级重新计算建筑价值、美观度 |
| `0x61DE00` | 总好感读取角色系统的实时合计 |

`ShopRankConfig`：bnzp 为累计营业额门槛，bnzq 为建筑价值，bnzr 为美观，bnzs 为总好感 ×1000。前三项显示时除1000。条件准备只调整 StatsData.IncomeMetrics 与现有 NPC favorValue；CurrentRank、解锁列表、物理评分缓存不写。目标 N 使用当前等级至 N−1 的各行门槛。

## 炼金解锁

`UI 0x7AA700 → 0x777680 → 0x77A470` 为正常解锁路径。它检查条件、扣费、执行各类效果、按天赋数更新炼金等级，随后发送 `UNLOCK_TALENT=84`。读档并不重放这条链。

| 配置字段 | 含义 |
| --- | --- |
| bmzw / bmzx | 天赋 ID / 名称语言 ID |
| bnaa | 工坊等级门槛 |
| bnac | 建筑0、配方1、剧情2、种子3、能力4 |
| bnae | 前置天赋，需要已解锁标记 |
| bnaf / bnag | 天赋点成本 / 原始金币成本 |
| bnah | ItemGroupConfig 材料组 ID |

`0x7795D0` 检查解锁条件；`0x779E80` 检查所有前置；`0x779FC0` 对配方额外检查原料的正常获得记录。当前炼金材料组均为 `bnpc=1 / bnpd=1`，使用 bnpe / bnpf 配对的物品与数量，其他模式拒绝近似计算。

入口通过主线200207“炼金入门”开放。剧情天赋由游戏剧情检查；六个剧情节点不批量写入。

110个天赋包含16个建筑、28个配方、6个剧情、21个种子和39个能力节点。只写 UnlockTalentList 无法恢复全部功能：配方对应 ProductSaveData.HeldProductList，建筑还需要配套库存；能力效果在获得时修改其他持久字段，读档的恢复回调不会补执行这些效果。因此本版本仅准备费用，不改解锁和等级。

## 验证

`python -m unittest discover -s tests -v` 在临时目录生成合成存档，覆盖成本合并、前置顺序、剧情与获得记录阻挡、上限、幂等、预览、导出、过期 SHA 和原字节逆向恢复。

真实存档只在内存中生成并还原方案。检查任务、配方、剧情、遗物、能力与等级记录保持原样，并重新核对源文件哈希。未替换真实存档，也未声称编辑器已执行游戏内事件。
