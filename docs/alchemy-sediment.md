# 炼金沉淀物

## 操作入口

- **存档编辑 → 炼金与天赋**：显示当前总量；点击数值可任意调整，快捷按钮可补足到 100、1000、10000。
- **一键方案 → 炼金准备**：默认补足沉淀物到 1000，保留更高现值。
- **自定义方案 → 炼金沉淀物**：可设置独立目标，保存、导入或导出方案。

直接填写整数数量。支持范围为 `0–2147483647`；这里采用当前游戏摘要的 int32 范围，避免保存时截断。

## 数据来源与联动

当前支持版本以 `AllAttributeSaveData.AttributeParams[]` 中 **AttributeId=902** 的 `Value` 作为实际可用总量，倍率为 1。字段通过 ID 查找，不依赖它恰好处于数组第二项。

`AlchemySaveData.AlchemyPrecipitatesValueList` 和 `AlchemyPrecipitatesNumList` 在当前版本中是摘要：游戏保存时写入一项总量和一项固定计数 `1`。其中的 `NumList=1` 不是实际可用沉淀物数量。

编辑总量时，工作台会自动同步当前版本的单条摘要。预览中会把额外变更标为“自动同步”，摘要不能单独编辑。若该存档没有属性 902，预设会报告没有适用记录；不会凭空创建未知记录。

## 原生代码依据

以下 RVA 对应 [受支持的游戏版本](compatibility.md)：

| RVA | 观察到的行为 |
| --- | --- |
| `0x778360` | `Piper.Alchemy.caf.sbu/sca` 传入 `0x386`（902）读取属性总量 |
| `0x7783D0` | 使用同一属性检查沉淀总量是否足够 |
| `0x778410` | 对属性 902 增加整数沉淀量 |
| `0x778460` | 对属性 902 减去整数沉淀量 |
| `0x418D91–0x418E63` | `AlchemyData.Save` 把读取到的总量写入 ValueList，再把 `1` 写入 NumList |

字段结构、数量单位和预览同步已核对。尚未通过修改真实游戏存档逐项验证游戏内效果。
