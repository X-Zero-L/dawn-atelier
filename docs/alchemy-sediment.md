# 修改炼金沉淀物

在 **存档编辑 → 炼金与天赋** 中找到“炼金沉淀物”卡片。

![炼金沉淀物数量与快捷补足](images/alchemy.png)

## 直接调整数量

1. 选择要修改的存档。
2. 点击卡片中的数量，输入想要的数值。
3. 将改动加入清单，查看预览后保存。

直接填写整数数量即可，无需倍率换算。支持 `0–2147483647`；快捷按钮可补足到 **100、1000、10000**，已有数量更高时不会减少。

## 加入一键方案

- **炼金准备**默认补足到 1000。
- 在**自定义方案**中勾选“炼金沉淀物”，可以设置自己的目标，并与材料、种子或天赋点补给组合使用。
- 保存为“我的方案”后，下次可以直接使用，也可导出给其他玩家。

## 保存前看什么

清单会显示沉淀物数量的原值和目标值。标注为“自动同步”的相关记录由工坊一并处理，无需单独修改。

![沉淀物修改预览](images/alchemy-preview.png)

可以导出副本，也可以退出游戏后“备份并直接应用”。进入游戏后，读取对应存档。

## 没找到记录或数值没有变化

- 确认选中的是最近保存的存档。
- 若提示没有沉淀物记录，先在游戏里获得一些沉淀物并保存，再重新读取。
- 快捷补足不会降低已有数量；需要减少时，直接点击数量进行修改。
- 如果游戏期间保存了新进度，先刷新存档，再重新生成修改。

修改前的原档可以从“导出与备份”下载。首次使用时请保留备份，并确认游戏读档后的效果。
