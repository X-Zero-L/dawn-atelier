# 炼金解锁与工坊升级准备

这两项功能会准备资源，并列出还需在游戏中完成的条件。保存、重新读档后，请在游戏原有界面点击解锁或升级，领取相应配方、建筑、能力和奖励。

## 炼金解锁准备

进入 **存档编辑 → 炼金与天赋 → 解锁条件**。

- 搜索天赋名称，查看工坊等级、前置天赋、金币、点数和材料需求。
- 点击 **准备这个天赋**，自动合并尚未解锁的普通前置天赋成本，列出建议解锁顺序。
- 点击 **准备当前可解锁项**，为当前工坊等级、剧情与原料获得条件允许的普通天赋一起备料。
- 预览并保存后，重新读档，在炼金天赋树中按顺序点击解锁。

已有数量更高时会保留，重复准备不会反复叠加物资。还缺工坊等级、剧情或原料获得记录的单项可以提前备料，但剩余条件会显示在预览中。

### 为什么材料够了，仍提示需要获得原料？

部分炼金配方还要求你曾在游戏里正常获得其原料。把物品加入背包不会伪造这段记录；请通过游戏里的采集、生产或交易获得对应原料，再尝试解锁。

### 炼金等级如何提高？

当前支持版本根据已解锁天赋数量提升炼金等级。原生解锁会同时处理等级、配方、建筑库存、能力效果和相关事件。

主线“炼金入门”开放炼金入口；故事节点继续随剧情完成。工坊等级门槛指工坊等级，与炼金等级是两套数值。

## 工坊升级准备

进入 **存档编辑 → 工坊成长**，选择目标等级，查看四项条件：

| 条件 | 准备方式 |
| --- | --- |
| 累计营业额 | 补足到目标等级所需数值，保留更高的现值 |
| 总好感 | 在已有角色之间补足缺口，遵守各自配置上限；预览可查看每个角色的变化 |
| 建筑价值 | 显示当前记录与缺口，需要在游戏中实际建造 |
| 美观度 | 显示当前记录与缺口，需要在游戏中实际布置 |

保存读档后，在工坊面板逐级点击升级。多级目标按途中各级的条件计算；等级、建筑与配方解锁、天赋点奖励由每次原生升级处理。

建筑价值和美观度会按实际布置重新计算，最终是否可升级以游戏面板为准。若已有角色的总好感上限不够，会列出仍缺的数值。

## 预览与撤销

准备结果先加入修改清单。可以逐项取消或整组撤销，保存前仍会备份原档。界面条件基于当前读取的存档；保存后重新读取可更新显示。

当前版本已核对游戏原生条件与调用链，并检查合成存档及真实存档副本的计算、可逆性和重复执行。准备操作保持等级、天赋、任务、配方和能力记录原样；实际解锁事件在你回游戏点击原生按钮时发生。
